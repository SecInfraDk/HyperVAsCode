# Modules

## Purpose

Provides Hyper-V-specific reusable functions and modules.

## Example contents

Helpers for platform connections, VM resources, storage, and networking.

## Scope

Platform-only functions remain here. Shared functions used across repositories belong in InfraModules.

## Dependencies

Hyper-V host access, the Hyper-V PowerShell module, and permissions for the target resources.
